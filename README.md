# sd_lib

A comprehensive framework library for FiveM resources, supporting QB, ESX, and QBX frameworks.

## Features

- **Framework Detection**: Auto-detects and works with QB-Core, QBX, ESX, or custom frameworks
- **Notification System**: Supports multiple notification systems (ox_lib, mythic_notify, okokNotify, etc.)
- **Progress Bars**: Compatible with ox_lib, qb-core, progressbar, and native
- **Text UI**: Works with ox_lib, esx_textui, qb-core, okokTextUI, and native
- **Skill Checks**: Supports ox_lib, ps-ui, and bl_ui skill check systems
- **Zones**: PolyZone and ox_lib zone support
- **Interactions**: ox_target, qb-target, lunar_bridge, and native/textui interactions
- **Voice System**: pma-voice and saltychat support
- **Dispatch**: Multiple dispatch system support (sd_dispatch, ps-dispatch, cd_dispatch, etc.)
- **Dialog**: ox_lib, qb-input, esx_menu_dialog, and native dialogs
- **Inventory**: Supports ox_inventory, ps-inventory, qb-inventory, and more
- **Job Management**: Complete job system with employees, grades, salaries
- **Player Data**: Unified player data access across frameworks
- **Vehicle System**: Vehicle spawning and properties
- **Callbacks**: Callback system

## Installation

Add this resource to your server and make sure it starts before other sd_* resources.

## Configuration

Edit `shared/config.lua` to configure:
- Framework detection (auto or specific)
- Notification system
- Progress bar system
- Text UI system
- Skill check system
- Zone system
- Interaction system
- Voice system
- Dispatch system
- Dialog system
- Inventory system
